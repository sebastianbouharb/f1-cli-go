# f1-cli-go

## Welcome to the F1 Stats Fetcher ! 🏎️ 🏁 🏆


## Usage
Download the file for your system from the Releases page.

Mac/Linux:
  chmod +x f1-mac-arm64
  ./f1-mac-arm64 --season (specified season year, ex. 2025)

Mac only: if it says the developer can't be verified, run
  xattr -d com.apple.quarantine f1-mac-arm64

Windows:
  .\f1-windows.exe --season (specified season year, ex. 2025)
